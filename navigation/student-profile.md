<div class="section-card">
<h2>🎮 Game Feature — UESL Project</h2>

<div class="game-feature-box">
One of the highlights of my work this year was building the <strong>game feature</strong> for our UESL (Unified Education & Student Learning) project.
</div>

The game feature was designed to make studying and learning more engaging by turning course content into an interactive experience. Here's what I built and how:

**What it does**
- Players answer subject-based questions to advance through levels
- The game tracks scores and progress in real time
- It's fully integrated into the UESL platform so it pulls live content

**How I built it**
- Used **JavaScript** for all game logic — state management, scoring, and level transitions
- Built the UI with **HTML/CSS**, keeping it responsive so it works on both desktop and mobile
- Connected it to our backend API so questions and answers are fetched dynamically rather than hardcoded
- Collaborated with my team to make sure the game feature aligned with the rest of the platform's design and data model

**What I learned**

Building this pushed me to think about user experience, not just code correctness. I had to balance game-feel (snappy feedback, clear scoring) with the educational purpose. It was also my first time writing a feature that communicated with a live backend in a meaningful way, which taught me a lot about asynchronous JavaScript and API design.
